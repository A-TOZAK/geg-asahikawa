GEG Asahikawa と GEG Chikuho の会で、School Stock の話をしました。当日の話を、あとから読み返せるようにまとめておきます。

School Stock は、教材とツールの置き場です

School Stock は、忙しい現場の先生が、登録も会費もなしで使える教材とツールの置き場です。プリント、ブラウザで動く道具、イラスト素材などを置いています。先生たちの時短につながればと思って作っています。

2026年7月末から数え始めて、ページは約4万回開かれ、教材は約2万回保存されています。

困っていることから作り、使いながら直しています

作るものは、自分や周りの先生が困っていることから決めています。AIを使って作り、教室で使ってもらい、出てきた声で直す。これを速く回し続けているだけです。

お金をもらって作っているわけではないので、完璧なものではありません。現場の先生なら、少し直して使える。そういう感覚で作っています。

たとえば、ふりかえりプリントでは「わり算の筆算のます目が足りない」という声をもらい、ます目を直しました。

当日紹介した7つ

  • ふりかえりプリント：毎日1枚の両面プリントです。表は算数、裏は国語です。答えは紙の端の帯にあり、子どもが自分で丸をつけます。漢字の習熟プリントや、わり算の筆算の練習もあります。
  • つかえるシリーズ：1単元を「きそ、よみとる、かんがえる、あらわす」の4まいで登るプリントです。校内では、応用問題に取り組むときに使っています。
  • デジタル国語辞典：小学生向けの国語辞典をブラウザで引けます。8,307語と、ことわざ、慣用句、四字熟語が約1,500本あります。
  • マス目プリントメーカー：1マスに1字入るプリントを作る道具です。縦書き、原稿用紙のきまり、筆算、板書計画の型にも対応しています。
  • デジタルそろばん：本物に近いそろばんを、ブラウザで動かせます。3年と4年の11コースがあります。実物にさわったあと、家で何度でも練習するための道具です。
  • 3年社会 デジタル副読本：3年の「市の様子」の資料を、書きこめる副読本にしました。飯塚市の資料で作りましたが、作り方の型はほかの市町村でも使えます。
  • イラスト素材集：授業やおたよりに使える無料の素材です。子ども向けの資料やプリントを作るとき、Claude Code もこの棚の絵を使っています。

作っている道具

教材の中身づくり、紙面の組み立て、PDFへの書き出しは、生成AIの Claude Code で行っています。紙面の文字はモリサワのフォントで組み、サイトは GitHub Pages で公開しています。AIに頼むときは、役割、条件、出力の形、差し替える欄を決めてから頼んでいます。

今日の資料も、School Stock の道具で作りました。全体像と道具ごとの板書はマス目プリントメーカー、話す順番と今日の地図は思考ツールボードです。
